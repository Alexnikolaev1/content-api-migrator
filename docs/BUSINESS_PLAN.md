## 1. Рынок и временное окно

### 1.1 Почему боль реальна
- Content API for Shopping снят; вызовы к старому endpoint дают **410 / тихую деградацию** фида.
- У части магазинов «сайт жив», а Google Shopping / бесплатные листинги **не обновляются**.
- Агентства и in-house, которые писали на Content API руками, не имеют «одной кнопки» в Shopify Google & YouTube.

### 1.2 Почему это окно, а не вечный рынок
| Фаза | Когда | Что происходит со спросом |
|---|---|---|
| Panic / early | уже сейчас | Высокий intent, мало кейсов у конкурентов-фрилансеров |
| Peak harvest | ~3–9 мес | Максимум сделок; все «кто мог» мигрируют |
| Long tail | 9–18 мес | Мелкие, сложные, откладывали; ниже willingness to pay |
| After | 18+ мес | Новых миграций почти нет |

**Следствие:** бизнес Continuity = **урожай 90–180 дней** + опциональный **retainer на Merchant API hygiene**. Без второго слоя вы строите фриланс-спринт, не компанию.

### 1.3 Размер (честная оценка, не TAM-театр)
Не оценивайте «весь Google Shopping». Считайте **достижимый** пайп:

- Соло outreach: 80–150 релевантных контактов / 90 дней  
- Конверсия в разговор: 15–25%  
- В тест фида: 30–40% от разговоров  
- В оплату: 40–60% от успешных тестов  

**База:** 100 контактов → 20 разговоров → 7 тестов → **3–5 сделок** в первый месяц при дисциплине. Масштаб до 8–12/90д реалистичен без рекламного бюджета.

## 2. Продукт и позиционирование

### 2.1 Что продаёте (одно предложение)
> Фиксированная миграция товарного фида с Content API на Merchant API за 48 часов: dry-run отчёт, staging upload, verify, delta/resume — без переписывания всего вашего backend.

### 2.2 Что НЕ продаёте (и это сила)
- Не «перепишем весь customBatch на async» в $990  
- Не accounts / shippingsettings / local inventory API  
- Не вечную поддержку «пока Google снова что-то не сломает» без retainer  
- Не замену Google & YouTube app для обычного Shopify

Явный out-of-scope на лендинге и в письме **повышает** закрытие: инженер-заказчик видит честность.

### 2.3 Позиционирование vs конкуренты

| Игрок | Их игра | Ваш угол |
|---|---|---|
| Shopify Google & YouTube | Кнопка для стандартного Shopify | Вы — для **кастома**, где app не закрывает |
| Агентства AtlanticWorks / feed-vendors | Контент + услуги, часто дороже/дольше | **48ч / фикс / инженерный отчёт** |
| «Сделаем на Claude сами» | DIY | Вы продаёте **риск и время**: micros, enum, verify, state — уже отлажено |
| Крупный SI | Долгие SOW | Вы — surgical fix, не трансформация |

**Дифференциатор:** воспроизводимый CLI + HTML audit + честный DELIVERY.md. Это не «починим как-нибудь», а артефакт, который CTO может проверить.

### 2.4 Бренд Continuity
Имя = непрерывность листингов. В коммуникациях всегда: **симптом → причина → фикс за 48ч → proof**.

## 3. ICP и анти-ICP

### 3.1 Ideal Customer Profile (покупает быстро)

**Компания**
- Ecom или performance-агентство, 1–50 человек  
- Каталог **примерно 200–50 000 SKU** (ниже 100 — часто «сами»; выше 100k — отдельный SOW)  
- Платформа: Magento / custom PHP-Node / headless / Shopify **Plus с кастомным фидом** (не дефолтный channel)

**Техпризнак (обязателен хотя бы один)**
- В коде/логах есть `shoppingcontent.googleapis.com`  
- Уже видели `410 Gone` или «фид не обновляется»  
- Нет стандартного Google & YouTube / аналога, который полностью владеет фидом  

**Человек**
- CTO / lead backend / head of performance / владелец агентства  
- Может дать **staging** data source и sample JSON за 24ч  

### 3.2 Анти-ICP (не тратить время)
- Чистый Shopify + Google & YouTube, «просто плохо крутится реклама»  
- Нужен полный rewrite интеграции / customBatch orchestration в одном $990  
- Нет доступа к Merchant Center / GCP  
- «Сделайте завтра бой без staging»  
- Тендер на 6 месяцев с 40-страничным RFP (не ваш цикл)

### 3.3 Сегменты по приоритету outreach

| Приоритет | Сегмент | Почему |
|---|---|---|
| P0 | Агентства, которые **строили** Content API фиды клиентам | У них портфель болей + повторные сделки |
| P1 | Mid-market brands с in-house фидом | Прямой budget, быстрее decision |
